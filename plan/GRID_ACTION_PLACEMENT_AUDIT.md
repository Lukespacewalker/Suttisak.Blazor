# ผลตรวจและปรับตำแหน่งคำสั่งในแอปที่ใช้ UI Lib

วันที่ 7 ตุลาคม 2026 — ตรวจครบ 7 repository หลัก และแก้ 24 ไฟล์ Razor พร้อม resource, tests และแนวทางใน Playbook

## หลักที่ใช้

- หน้าแสดงรายการหลัก: เพิ่ม/สร้าง และนำเข้าข้อมูลทั้งหน้า อยู่ใน `PageHeading.PageActions` โดยมีปุ่มหลักหนึ่งปุ่มและปุ่มรองที่ใช้บ่อย
- ค้นหา กรอง รีเฟรช และส่งออกข้อมูลตามมุมมอง อยู่ใกล้กริด
- คำสั่งที่ใช้กับรายการที่เลือก อยู่ในแถบการเลือก และมีปุ่มล้างการเลือก
- หน้าที่มีหลายกริดอิสระหรือกริดย่อย: ปุ่มเพิ่มของแต่ละกริดอยู่ใกล้กริดนั้น
- รักษา callback, route, สิทธิ์, เงื่อนไข loading/disabled และการยืนยันลบเดิม

งานนี้รักษา workflow ที่ใช้การเลือกแถวเดิม และยังไม่ได้เพิ่มการกดพื้นที่ทั้งแถวเพื่อเปิดรายละเอียด

## การแก้ในแต่ละแอป

| แอป | สิ่งที่ปรับ |
| --- | --- |
| AudiogramIQ | หน้าบัญชีมีสองกริดอิสระ จึงวางเพิ่มผู้ใช้และอนุญาตอีเมลไว้กับกริดของตน ปุ่มเพิ่มผู้ใช้ยังใช้งานได้ระหว่างโหลดตามเดิม; นำเข้าผลตรวจอยู่ที่ heading ของหน้าสรุป; ส่งออกรายการที่เลือกอยู่ในแถบการเลือก |
| BafsWorkout | เพิ่มผู้เข้าร่วมอยู่ที่ heading; เพิ่มผู้ดูแล/รอบตรวจอยู่ที่ heading; แก้ไขและลบรายการที่เลือกอยู่ในแถบการเลือก |
| CoeKPI | เพิ่มบัญชี/รอบประเมินอยู่ที่ heading; แก้ไขและลบรอบที่เลือกอยู่ในแถบการเลือก; ส่งออก KPI อยู่ใกล้ตัวเลือกรอบรายงาน |
| ErgoTrack | เพิ่มผู้เข้าร่วม ผู้ดูแล บริษัท และรอบ อยู่ที่ heading; เพิ่มคำถาม/บันทึกคลังคำถาม และบันทึกชุดคำถามของรอบอยู่ที่ heading; ตัดปุ่มเพิ่มซ้ำใน empty state |
| HealthInsight | แชร์ลิงก์สรุปและบันทึกผลตรวจทั้งรอบอยู่ที่ heading; paginator, ขยายรายการและ PDF อยู่ในบริเวณข้อมูล |
| HRASystem | เริ่มรอบประเมิน เพิ่มบริษัท เพิ่มมาตรการ และการนำทางระดับหน้าอยู่ที่ heading; ปุ่มเพิ่มพื้นที่/แผนก/SEG ของกริดย่อยยังอยู่กับกริดนั้น |
| MentalInsight | นำเข้า JSON อยู่ข้างเพิ่มผู้ใช้ใน heading พร้อม label และคำอธิบาย; หน้า report แสดงดาวน์โหลดหลักและรวมดาวน์โหลดเพิ่มเติมไว้ในเมนู โดยรักษาทุก callback |

ปรับชื่อแถบคำสั่งสำหรับโปรแกรมอ่านหน้าจอให้ใช้ภาษา/resource ของแต่ละแอป และอัปเดต [แนวทางใน Playbook](../Suttisak.Blazor.Playbook/GRID_ACTION_GUIDELINES.md) พร้อมประวัติการตัดสินใจ

Browser tests ใช้ฐานข้อมูล PostgreSQL ที่สร้างแยกและลบทิ้งเมื่อจบ ไม่ใช้ฐานข้อมูลจริง ตรวจว่า document ไม่ล้นแนวนอนในสถานะที่ทดสอบ และตรวจภาพมือถือของ BafsWorkout, ErgoTrack และ MentalInsight เพิ่มด้วย

หลักฐานการกดในเบราว์เซอร์ครอบคลุมหน้าที่ระบุในตาราง ไม่ได้ทดสอบด้วยเบราว์เซอร์ทุกหน้าของทุกแอป

## ข้อจำกัดจากโค้ดเดิม

- AudiogramIQ แบบ Debug ยังติด `Program.cs:59` ที่อ้าง `CompactHeaderPreferences` ซึ่งไม่มีใน Lib ปัจจุบัน; แบบ Release ผ่าน
- MentalInsight แบบ Release ยังติด override ใน `NexoraLoginLayout.razor` ที่ต้องใช้ API ใหม่กว่าของแพ็กเกจเดิม; แบบ Debug กับ Lib ใน workspace และ browser tests ผ่าน
- มี warnings เดิมจากบาง repository ซึ่งไม่ได้แก้ในงานจัดตำแหน่งปุ่ม

งานนี้ไม่เปลี่ยน public API ของ Lib, version หรือ package/project references จึงไม่มีการ release แพ็กเกจหรือ push repository

## การตรวจอิสระ

Root เป็นผู้แก้ไฟล์ทั้งหมด ผู้ตรวจอีก session ตรวจแบบอ่านอย่างเดียวจาก snapshot ก่อนแก้และ hash ของผลสุดท้าย แยกจาก dirty changes เดิม ยืนยัน hash ครบ 37 ไฟล์และ baseline เดิม 36 ไฟล์ ตรวจภาพจอปกติ/มือถือ 10 ภาพ และอ่านรายงาน browser tests ทั้งสามแอปซึ่งผ่านรวม 6/6

ผลตรวจอิสระ: **PASS สำหรับตำแหน่งคำสั่งและการรักษา safeguards ในงานนี้** ไม่มีข้อแก้ไขที่ต้องทำเหลืออยู่ รายการที่พบเรื่อง label ได้แก้แล้ว ข้อจำกัดของ build คนละ configuration และขอบเขตหลักฐาน UI ยังคงเป็นไปตามที่ระบุด้านบน
